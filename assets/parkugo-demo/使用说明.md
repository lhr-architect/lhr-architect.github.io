# Park U Go · 离线前端演示

**双击 `index.html` 即可运行**，不需要服务器、不需要启动后端。所有页面跳转与玩法都保留。

> 推荐用 **Chrome** 打开（手机尺寸更像真机：开发者工具 → 切换设备工具栏）。

## 和正式版的区别

| 正式版需要 | 演示版的替代 |
|-----------|-------------|
| 后端服务器（房间/对战/计分） | `demo-backend.js`：在浏览器内运行的后端，逐条移植自 `backend/server.py`，规则一致 |
| 其他真人玩家 | 每个阵营 2 个演示机器人（如 `CYAN-01`），被击倒 30 秒后自动复活 |
| 真实 GPS | 位置固定在**未名湖南岸**，在哪台电脑上打开都一样 |
| 手机摄像头 | 有摄像头就用真实摄像头；没有/拒绝授权时自动换成合成取景画面（未名湖 + 博雅塔；前置为自拍头像） |
| 绕据点走一圈拍三张 | TOWER 模式下拍的照片自动落在所选据点周围的三个顶点上 |
| 走到石坊复活 | 选「石坊复活」时自动模拟走到石坊 |
| CDN 上的 Leaflet / html2canvas | 已放在 `vendor/`，本地加载 |

`app.js`、`styles.css` 与最终版（`../web/`）**完全相同**，未做任何修改；演示能力全部在 `demo-backend.js` 和 `demo-ui.js` 两个附加文件里。

## 演示路线建议

1. **首页** → 输入任意玩家名 → ENTER → 权限页 GO → 选角色 / 阵营 → LOCK → GO ▶ 进入战场
2. **KILL**：按快门拍照装弹 → 转盘选敌人（机器人）→ 滑动开火
3. **TOWER**：REPORT 打开总览 → 选一个据点 → 拍 3 张 → 在左侧选中这 3 张 → 下拉滑块占领
4. **角色差异**：
   - PRIEST：可治疗受伤队友，也能救活倒地队友（演示场景里已安排好）
   - MARTYR（wizard）：先翻转到前置摄像头自拍，再开火 → 自焚，10m 内敌人各 -1
   - SNIPER：一次 2 点伤害
5. **CHECKMATE 模式**：首页切到 CHECKMATE tab。KING 可读条放置据点；其他角色可用 3 张照片摧毁敌方据点（场上已有 3 个敌方据点）
6. 右下角 **DEMO** 菜单：
   - 立即倒地 → 演示死亡页、跳舞复活（60 秒）/ 石坊复活
   - 立即结算 → 演示结算页、保存截图、行动回顾
   - 重置全部演示数据

## 特殊房间名

| 房间名 | 效果 |
|-------|------|
| `test`（默认） | 无时间限制 |
| `testdeath` | 进入战场 5 秒后自动倒地（演示死亡流程） |
| 含 `fast`，如 `fast1` | 对局 3 分钟到点自动结算；CHECKMATE 下读条/冷却也 10 倍速（如 `mate-fast1`） |
| 其他 | 标准 30 分钟对局 |

## 注意

- **地图底图需要联网**（OpenStreetMap 瓦片）。断网时底图为空白，但据点、玩家、视野圈照常显示，其余功能不受影响。
- 演示数据存在浏览器本地（localStorage），刷新页面不会丢；用 DEMO 菜单「重置全部演示数据」清空。
- 原版 `photos.html`（服务器照片列表工具）依赖真实服务器，演示版不包含。
